Quick reference:
  python output_generator.py config-socal-align.ini     # generate the map
  python serve.py config-socal-align.ini --port 8000     # serve + edit area labels live
  -> open http://127.0.0.1:8000/

The serve.py workflow lets you add/edit/move/rotate area labels directly in the
browser (no copy-paste, no regenerate). See the "Edit area labels live" section of
README.md.
